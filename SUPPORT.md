# Support

## Questions and troubleshooting

Start with the [troubleshooting guide](website/docs/troubleshooting.md) and the
[GrowCam C4 setup guide](website/docs/growcam-c4-setup.md). They cover the
camera connection, credentials, local network access, playback, downloads, and
common installation problems.

If the guides do not resolve the problem, open a
[GitHub issue](https://github.com/Nick2bad4u/growcam-pc/issues/new/choose). Use
the bug report template for reproducible failures and the feature request
template for proposed behavior changes.

Include the GrowCam PC version, operating system, Python version, camera model,
relevant command output, and sanitized logs. Remove camera credentials, private
network addresses, tokens, and other secrets before posting.

## Security reports

Do not report vulnerabilities or exposed credentials in a public issue. Follow
the private reporting process in [SECURITY.md](SECURITY.md).
